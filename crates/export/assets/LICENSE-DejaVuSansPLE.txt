This repository carries a deterministic subset of DejaVu Sans in
DejaVuSansPLE.ttf. It was made from the DejaVu Sans distribution
with fonttools/pyftsubset for the Unicode ranges used in ordinary scientific
exam content (ASCII, Latin-1, Greek, superscripts/subscripts, arrows and
mathematical operators).  The font file is embedded in every generated PDF;
no host font is used at build or runtime.
