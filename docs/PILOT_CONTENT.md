# Pilot content import

BPW owns the subject content, task selection, and build pipeline. PLE imports directly from
its build outputs through [import_bpw.py](../launchers/import_bpw.py), using BPW topic and
problem-set metadata. See [README.md](../ple_import/README.md) for the import command and
[FALL_2026_PILOT.md](FALL_2026_PILOT.md) for teaching scope.

The former local Genetics bundle and curated eight-question Chapter 1 set have been removed.
The miniature publisher was already retired. PLE keeps imported Questions in its ordinary
application storage, with provenance and licensing supplied by the importer.

Fresh installation imports BPW collections and adopts Biochemistry through ordinary HTTP
workflows. See [LIVE_DEMO_SPEC.md](LIVE_DEMO_SPEC.md) for representative Student Work.
