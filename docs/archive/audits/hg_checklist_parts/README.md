# Human Guidance checklist source parts

These nine files are active inputs to `devel/human_guidance_checklist.py`, which names this
directory as `PARTS_DIRECTORY` and generates
`docs/active_plans/audits/human_guidance_implementation_checklist.md`. The archive path reflects
where the parts were collected; it does not make them immutable historical records.

The parts organize Human Guidance text for review. Their presence does not turn every broad
guideline into a separately closable product requirement. Use the Human Guidance source and the
owning product contract to decide applicability, implementation scope, and acceptance evidence.
