# Biotechnology base Course

## Scope

Biotechnology is a named Fall 2026 pilot source collection, not a complete source course.
[BiologyProblems.org](https://biologyproblems.org/) lists it among selected Question collections;
only Genetics and Biochemistry are complete courses. Neil confirmed this distinction.
He explicitly kept Biotechnology in the first delivery despite its incomplete coverage.

The source root is `OTHER_REPOS/biology-problems-website/site_docs/biotechnology/`. The Course
color preference is brick red (`#9e3d32` header/light accent and `#f28b82` dark accent). `Magma`
is the proposed PLE Theme because it has warm red surfaces and a brick-red Light accent. Confirm
it through Light and Dark visual review before assigning it.
