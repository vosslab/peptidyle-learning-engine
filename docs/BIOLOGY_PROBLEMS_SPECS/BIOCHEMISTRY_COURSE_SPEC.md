# Biochemistry base Course

## Scope

Biochemistry is a complete first-semester source course. This specification inventories available
source material for a future base Blueprint Course. It does not claim that all listed content has
been imported or that its final Assessment grouping has been decided.

The source root is `OTHER_REPOS/biology-problems-website/site_docs/biochemistry/`. The Course
color preference is purple (`#7b1fa2` in the syllabus guide). `Tundra` is a tentative PLE Theme:
its lavender surfaces are a partial match, while its green accents require visual review in Light
and Dark appearances. This is not a new theme or a confirmed default.

## Blueprint Course mapping

| Input | Target | Status |
| --- | --- | --- |
| All listed Biochemistry topics | One reusable Biochemistry Blueprint Course | Intended base Course; source is complete. |
| Each topic or selected problem-set subset | Ordered Blueprint Modules and Assessments | Open; do not infer grouping from directory numbers. |
| Reviewed interchangeable Questions | Question Pool where Pool rules are met | Optional and open per set. |
| Individual Questions | Fixed Assessment entries | Available where selected by the Course definition. |

The current Chapter 1 pilot subset is not the final Course inventory. It has four Biochemistry
Questions (two WeBWorK and two native JSON) in one teaching Assessment; see
[../PILOT_CONTENT.md](../PILOT_CONTENT.md). It provides a validated example, not a cap on this
Course or a settled structure for all topics.

## Remaining Course content work

Use the topic-based organization in
[BIOLOGY_PROBLEMS_COURSE_IMPORT_SPEC.md](BIOLOGY_PROBLEMS_COURSE_IMPORT_SPEC.md): one Assessment
per topic to start, splitting long topics into parts and usually treating Hard Questions as bonus.


Assessment grouping, selected problem sets, points, Pool use, and reusable defaults are
[Q02 in the central question log](../active_plans/decisions/question_specs_open_questions.md).
Course classification and final Theme review are normal Course-definition work, not an implied
mapping from this source inventory.
