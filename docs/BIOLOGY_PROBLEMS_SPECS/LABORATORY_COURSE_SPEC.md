# Laboratory base Course

## Scope

Laboratory is a partially complete source course. It starts with measurement basics, solutions,
and dilutions, with available material for additional laboratory methods. It can seed a Blueprint
Course but does not claim complete laboratory curriculum coverage.

The source root is `OTHER_REPOS/biology-problems-website/site_docs/laboratory/`. The user selected
teal-green as this Course's color family. No exact RGB value or existing PLE Theme has been chosen.
