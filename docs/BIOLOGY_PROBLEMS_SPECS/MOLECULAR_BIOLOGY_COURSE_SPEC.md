# Molecular Biology base Course

## Scope

Molecular Biology is a partially complete source course. It covers core molecular biology,
including PCR, cloning, gene expression analysis, and related techniques. Partial completeness
means that available topics can support a base Course, but they do not establish complete coverage
for a full Molecular Biology curriculum.

The source root is `OTHER_REPOS/biology-problems-website/site_docs/molecular_biology/`. The user
selected magenta as this Course's color family. No exact RGB value or matching existing PLE Theme
has been chosen; the Course specification must not invent one.
