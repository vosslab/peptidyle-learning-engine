# Ribbon retirement responsibility inventory

This inventory is the completed M11 retirement record for the superseded course-navigation layers. It records each observed responsibility, its single post-retirement owner, and the evidence used to verify deletion. The Ribbon remains the persistent navigation surface; page content owns its own purpose, heading, and recovery state.

## Scope and rule

The retiring files are `src/components/course_management_frame.tsx`, `src/components/course_management_nav.tsx`, `src/pages/assignment_workspace/assignment_workspace_nav.tsx`, and `src/features/course_appearance/course_theme_route.ts`. M10 has already introduced `src/application_shell.tsx`, `src/ribbon/route_scope_context.tsx`, and `src/features/course_appearance/course_theme_variables.tsx` as their replacement seams.

The listed owners are the current authority. A row marked BLOCKED would stop retirement; an intentional removal is not BLOCKED when it has no promised replacement behavior.

## Completed retirement order

M11 followed this order so compilation and targeted checks exposed an omitted ownership transfer before a broad deletion could conceal it.

1. It established the page-heading, `New assignment` Page Action, and route-specific missing-data checks, making page ownership observable before context removal.
2. It migrated the twelve consumers from `useCourseThemeRouteData()` to `useRouteScopeData()` and retained `CourseThemePresentationContext` only through `CourseThemeVariables`.
3. It deleted the compatibility `CourseThemeScope`, `CourseThemeRouteContext`, old hook, and duplicate `courseThemeRouteRequest` classifier; `npx tsc --noEmit` passed immediately afterward.
4. It retired `CourseManagementFrame`, `CourseManagementNav`, and `AssignmentWorkspaceNav`, including their imports, styles, and legacy-navigation tests, after the Page Action was owned by the course page.
5. It removed the special `data-route-surface` width block, the `workspaceList` placeholder route/type/component mapping/tests, and the dead sysadmin-only access-denial branch. It preserved all `data-route-surface` attributes and retained `myQuestionDrafts` as an unbacked closed future identity in the catalog and registry.
6. It ran the DOM/identity, route contract, scope, theme, workspace, and typecheck gates. The clean dead-export scan was one-time closure evidence for this deletion, not a permanent source-inventory test; the repository-wide aggregate is recorded separately when its current run is available.
