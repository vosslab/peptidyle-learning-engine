# Native JSON specification location

The internal source format is specified in
[NATIVE_JSON_SPEC.md](QUESTION_SPECS/NATIVE_JSON_SPEC.md). QTI format mapping is separately defined
in [QTI_INTERCHANGE_SPEC.md](QUESTION_SPECS/QTI_INTERCHANGE_SPEC.md), with workflows in
[QUESTION_IMPORT_SPEC.md](QUESTION_SPECS/QUESTION_IMPORT_SPEC.md) and
[QUESTION_EXPORT_SPEC.md](QUESTION_SPECS/QUESTION_EXPORT_SPEC.md).

This historical filename is a navigation page, not a QTI JSON format or a second Native JSON
specification. The focused files above own all current rules.
